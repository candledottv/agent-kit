# Contributing

This repository is a **read-only mirror**. A sync generates it from Candle's own source, so a pull
request opened here cannot be merged: the next sync would overwrite it.

## How to help

- **Open an issue here.** Bug reports, missing capabilities and confusing docs are welcome, and
  issues are read. Include the tool or SDK call you made, the error code you got back, and what
  you expected. Remove API keys, wallet addresses you consider private, and recovery phrases
  before you post.
- **Command line and wallet problems** belong in [candledottv/cli](https://github.com/candledottv/cli/issues).
- **Prose documentation** lives at [docs.candle.tv](https://docs.candle.tv).

## Security

Do not open a public issue for a vulnerability. Follow the disclosure process at
[docs.candle.tv/legal/vulnerability-disclosure](https://docs.candle.tv/legal/vulnerability-disclosure).
